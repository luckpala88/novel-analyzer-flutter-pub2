# 网文拆解器 APP 使用手册

> 版本基准 v965 · 本手册由源码提取，内置APP设置页，供用户查阅与AI答疑引用

## 0. 全局架构（先读这个）

**三层拆解体系**：弧线（Arc，叙事段）→ 场景（Scene，地点/人物集合的情节单元）→ 分镜（Shot，场景内最小叙事单位）。数据流：

```
章节txt → 弧线扫描(步进切片) → 场景划分 → 分镜拆解 → 世界书条目(唯一汇合点) → 改编/续写/创作
```

**单一事实源（v916重构）**：弧线分析、场景拆解、分镜拆解三容器存同一实例，改一处全链生效；加载时重绑。

**世界书中心律**：创作的一切依据是世界书（改编后条目优先），不回退原始分析数据；续写/分镜页展示层读分镜拆解数据，写入条目后即与世界书汇合。

**版本号三处铁律**：pubspec.yaml / home_page.dart `_appVersion` / app_version.dart `v` 必须一致。

## 1. 首页

- **书管理**：多书切换（笑傲江湖/通天之路/修真世界），每书独立数据目录。
- **章节导入**：txt导入，自动按章节标题切分；**章节正则可在设置自定义**（小章书适配）。
- **阅读器**：📑翻页（TextPainter精确分页+圆形↑↓按钮+跨文件自动翻页）/📜滚动（可编辑可保存）双模式；A-/A+字号；页码标题全塞信息行（不浪费 AppBar 面积）。
- **API基础设置**：内置提供商（智谱/DeepSeek/Gemini官方/自定义）+中转；Key填后自动从/models拉真实模型列表；per-provider独立保存，切换不清Key。
- **备份/云同步**：格式与v318互通；公共目录/专属目录存储模式（旧手机用专属目录）。

## 2. 场景页（两步拆解主链路）

弧线扫描出候选后，**全部拆解走这里两步**：

- **第1步 划分场景**：AI按弧线正文划分场景（地点/人物/情节单元切分），输出场景N：名称+概述。**温度建议0.3-0.5**（0.1会偷懒合并场景）。
- **第2步 拆分镜**：对每场景拆最小叙事单位，输出镜级分界句→锚点snap→shot.text物化。
- **扫描配方**：Pro系模型+温度0.3+步进10（通天之路甜区）；步进1-2闭合偏早、20偏晚，**步进敏感度与模型强相关**；小章书（2500字/章）默认步进1。
- **⚙折叠面板**：每页顶部API参数独立（本页温度/模型等），不集中管理。

## 3. 弧线页（Scan）

- **扫描进度卡**：按弧线N显示扫描状态；弧线卡=标题+状态徽标。
- **弧线闭合规范**：能闭合就闭合（主角不可逆变化）；伪闭合宽容（多切无害漏切有害）；弧线连续不交叉，相邻可共享边界章。
- **切片🔍**：任何卡上的🔍按钮=弹出原文切片对照（可复制）。
- **验收硬指标**：无丢失无重叠顺序对应；文本级锚点切分不重叠。

## 4. 分析页

- **🧠分析弧线**：对扫描完成的弧线跑深度分析（词链/编排策略/trick四问），结果存arcAnalyses。
- **词链**：弧线内高频词与伏笔链；**含编排+trick字段**。
- **三层策略**：弧线内场景编排策略 / 场景内分镜编排策略 / 镜内表述策略（trick四问）——分析全自动+独立按键。

## 5. 改编页（4子Tab，浅蓝=续写、金棕=改编）

### 5.1 弧线工作台
- **改编ABC三阶段**：A原文→B改编指令注入→C成品；策略库+心法六原则自动注入prompt。
- 弧线卡：🎭标题+▾/▸手动折叠（ExpansionTile在TabBarView冻死的教训，全部手写折叠）。

### 5.2 场景工作台
- **素材注入块**（🧩素材）：空=不注入；AI规划/细化时"有机融入"要求写进prompt。
- 场景行：改编指令逐场景编辑；控制器与暂存区同步（漏同步=框空白的教训）。

### 5.3 分镜续写
- 新场景沿分镜模式：AI规划新场景的分镜（规划框可手改）→📝**写入条目**→落世界书→创作页走"沿分镜"。
- 弧线卡展开后：场景tile列表+🧩AI分镜规划按钮+规划框+写入条目；**规划结果在框内直显**（v964修同步）。
- 序号校验：拆解场景数与条目已写数错位会拦截报错。

### 5.4 场景续写
- 与改编**二选一互斥**；独立UI/独立prompt/独立存储，不共用代码分支。
- 弧线卡（▾/▸手动折叠v963）→场景行（概述+🔍切片）；AI规划场景（新场景号=max+1）→写入条目。
- **续写采集禁拟新名**：只登记用户新名（防AI编造角色污染世界书）。

## 6. 世界书页

- **条目结构**：每弧线一条目，content含`场景N：`段落；continuePlans存各页暂存（shot_plan_N=分镜规划等）。
- 列表限高滚动约3条；章节标题全显不截断。
- **世界书在就能创作**：不依赖扫描数据在线。

## 7. 创作页

- **三层表述优先令**：改编后表述>策略库trick>默认风格；心法六原则+策略库自动注入。
- **续写分镜规划**：有分镜规划=沿分镜创作；新场景无分镜=自由创作。
- **语料注入**：续写语料从分镜拆解数据采集（纯文本零emoji）。
- 输出txt=纯正文+章节标题，无结构标记；max_tokens上限100万（不做硬截断）。

## 8. 检测页

- **机器层**：字数±20%校验（代码直接查）；防抄检查。
- **AI层**：AI质检员（拿不准=pass）。
- **开关化铁律**：每个烧API或拦输出的机制配MiniButton开关（默认开，关=零成本）。

## 9. 聊天页

- AI对话独立页；可引用世界书条目上下文；终端日志可复制、多行选择、自动滚动到最新。

## 10. AI沟通协议（prompt要点速查）

| 功能 | 温度 | 关键注入 |
|---|---|---|
| 弧线扫描 | 0.3 | 步进切片+锚点句 |
| 场景划分 | 0.3-0.5 | 弧线全文+闭合规范 |
| 分镜拆解 | 0.3-0.5 | 场景全文+镜级分界句要求 |
| 弧线分析 | 0.3 | 词链+三层策略+trick四问 |
| 改编 | 0.5-0.7 | ABC指令+素材块+策略库 |
| 分镜规划 | 0.4 | 条目已有场景+max+1编号 |
| 场景规划 | 0.4 | 禁拟新名铁律 |
| 创作 | 0.7 | 三层优先令+心法+语料 |
| 检测 | 0.2 | 字数区间+防抄 |

- 所有发给AI的内容**纯文本零emoji**（emoji只在浏览层渲染）。
- 折叠输入框默认收起一行label，点击展开——**内容空白先想同步问题**。
- 中转与官方混用：Gemini免费tier用flash系（pro配额0）。

## 11. 常见问题

- **卡片点不开**：ExpansionTile遗留问题已全清（v963）；手写折叠▾/▸才是新交互。
- **规划框空白**：v964已修控制器同步；旧版重现=暂存与控制器断链，重新进页或重跑规划。
- **浮层负高度崩溃**：浮层禁top+bottom双约束（键盘弹出=布局崩溃循环）。
- **数据"消失"**：清APP数据二分法——能启动=数据问题，不能=代码问题；自检日志"文件不存在"=写盘层先查权限。
- **"成功"提示虚报**：检查计数是否在自检之后。
